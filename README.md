# Никита Орлов

**Инженер сетевых систем · ускорение ИИ**

Разрабатываю сетевые и инфраструктурные утилиты, оптимизирую инференс
нейросетей, пишу на **Go**, **Python** и **Rust**.

---

### Направления

- 🌐 **Сети** — TCP/UDP, прокси, балансировка, диагностика трафика
- ⚡ **Ускорение ИИ** — батчинг, квантизация, кэш, маршрутизация запросов к моделям
- 🛠 **Инфраструктура** — CLI-инструменты, сервисы, автоматизация
